# 穗光琥珀存档匣

一款个人使用的原生 iOS 17+《星露谷物语》1.6 存档编辑器，所有存档处理在设备本地完成。

源码版本：`0.5.0`（构建 `11`）

本次完善魔法地图、人物外观、房屋与房间：增加地图搜索与坐标范围操作、单株浇水、外观颜色编辑，以及可搜索的房间样式库和批量套用预览。具体规则见 [WORLD_EDITOR_UPDATE.md](WORLD_EDITOR_UPDATE.md)。此前背包与人物关系的增强记录保留在 [REFERENCE_EDITOR_UPDATE.md](REFERENCE_EDITOR_UPDATE.md)。

构建 11 已完成设备 Release 构建与模拟器 Debug 验证：实际执行 100 项测试，全部通过，其中包括新增的 18 项存档回归与 3 项界面测试。七张本轮原生截图已检查，结果和范围见 [构建 11 验证记录](validation/BUILD11_VERIFICATION.md)。构建 10 的 79 项通过记录保留在 [历史验证记录](validation/BUILD10_VERIFICATION.md)。

## 当前功能

- 四栏主界面：主页、追踪、工具、设置；底栏不再混入单个修改板块
- 主页展示游戏日期、累计游玩时间、存档中的真实外观参数，以及使用游戏像素素材的农场概览
- 追踪页以固定分类胶囊、总览农场摘要和四个可折叠分组组织全部 11 个只读模块；详情支持横向切换，配方支持搜索与解锁状态筛选
- 所有修改统一放在工具页；角色数值、人物外观、房屋、背包、财富进度、关系、技能职业、钱包能力、动物、配方与检查保存分别进入
- 未保存草稿可在各修改板块之间保留，最后从“检查与保存”统一写回
- 首次通过系统文件选择器授权外层 `Stardew Valley` 文件夹并自动发现全部存档，也可选择单个农场目录或同时选择主存档与 `SaveGameInfo`
- 编辑玩家、农场、日期、金钱、生命和体力；人物外观页提供原始/草稿对照、性别、发型、肤色和饰品选择库、编号输入，以及发色/眼睛/裤子颜色的选色器、色值输入与恢复
- 编辑五项技能的等级、精确经验值和 5/10 级分支职业
- 编辑齐钻、齐币、累计收入、金色核桃、干草及矿洞进度，并只读汇总天气、任务和收藏统计
- 编辑 1.6 钱包特殊物品与能力；使用 `mailReceived` 标记写回并保留未知邮件标记
- 查看和编辑农场动物名称、亲密度、心情、饱食度与饲养天数，支持一键恢复全部最佳状态
- 编辑农舍升级等级，以及存档中已经存在的现代/旧版房间墙纸和地板字段；支持房间搜索、表面对照、可搜索样式网格、指定房间批量套用预览和整房间恢复
- 支持标准背包 12/24/36 格容量调整、搜索与槽位筛选；编辑、移动、复制、清空背包物品，并从 1.6 物品目录添加普通物品；598 个可安全添加物品均有中文名与图标，包含八种已确认的 1.6 字符串 ID 物品；支持完整分类浏览、收藏、最近添加和数量直接输入
- 修改 NPC 好感度以及安全的朋友/约会状态；按筛选结果预览并批量补满好感，重置已有今日/本周送礼次数
- 解锁烹饪和制作配方；内置 231 条配方均显示简体中文名称、英文原名与分类图标
- 离线作物计算器：内置 47 种 1.6 作物，按游戏生长阶段规则计算成熟日、跨季收获、稻田加成、生长激素、职业、基础产量与收益
- 魔法地图：解析主存档 Farm 节点并按坐标绘制作物、树木、物件、建筑、户外动物和大型资源；支持名称/种子 ID/坐标搜索、类型与待处理筛选、矩形坐标范围、列表定位，以及全屏平移、双指 1–4 倍缩放与复位
- 农场操作：给有效且未浇水的存活作物浇水，清理散落石块、杂草、枯枝；支持全图、当前筛选范围或单个对象，范围操作先预览清单，单项操作可撤销，确认保存时才写回
- 保存前显示差异，只写实际变化字段；自动备份两份文件，并在失败时回滚
- 新备份记录 SHA-256 完整性摘要，手动恢复与中断恢复前都会校验
- 保存最近使用目录的安全书签，支持恢复应用内备份
- 支持普通 XML 与 zlib 压缩存档
- 编辑页与地图提供占用独立布局空间的固定检查入口，末行可完整滚动到按钮上方；检查页显示全部差异并支持逐项撤销，地图操作列出具体对象与坐标
- 双文件事务按文件来源绑定；未知新进度先保留保护备份，发现冲突时由用户选择处理方式
- 备份页支持手动创建保护备份、校验和独立导出；原存档无法打开时也可导出已有有效备份
- 文件读取、解压、解析和写回交给串行后台服务；工作期间锁定草稿并显示处理状态
- 在既有 55 张资源基础上，从用户提供的 859 张游戏素材库中筛选接入 58 张：11 种农场动物、8 种果树、7 位补充 NPC、鱼塘，以及 31 张用于板块入口、技能、进度、钱包、地图和空状态的识别素材；当前共打包 113 张位图

## 运行与验证

使用 macOS、Xcode 16+ 打开 `PelicanSaveEditor.xcodeproj`；工程已注册所有源文件。选择自己的签名 Team 后运行到 iOS 17+ 设备。源码包不包含证书或签名资料。

- 静态工程与资源检查：`python3 scripts/verify_release.py`
- 可选 Swift 语法扫描：`python3 scripts/check_swift_syntax.py`（需要 tree-sitter 0.26.0、tree-sitter-swift 0.7.3）
- 原生编译及全部测试：`bash scripts/validate-on-macos.sh`
- 未签名 IPA：`bash scripts/build-unsigned-ipa.sh`

静态检查不等同 Swift 编译、XCTest 或设备验收。既有历史记录保留在 validation/ 与 VALIDATION.md 中。

## 新增编辑规则

- 只对具有有效标准 `maxItems` 字段的背包开放 12、24、36 格；未知或扩展容量保留原值。
- 缩容时末尾仍有物品会阻止操作；撤销扩容同时恢复新解锁的槽位，保留旧槽位上的其他修改。
- 人物批量操作以当前搜索和筛选结果为范围，先显示受影响角色与变化值，确认后加入草稿。
- 补满好感按当前状态达到 8、10 或 14 心，保留更高好感，不自动改变关系；未知、订婚和离婚角色不参加批量补满。
- 送礼重置仅将已有有效的 `GiftsToday` / `GiftsThisWeek` 清零；不增加缺失字段，不改好感、婚姻、聊天标记或送礼日期。
- 所有修改仍由“检查与保存”统一写回，自动备份、事务回滚、差异撤销与文件来源隔离继续生效。

## 兼容性与数据来源

面向游戏 1.6.x，当前编辑主玩家。社区中心、完整箱子/冰箱、建筑、家具、剧情与其他联机玩家编辑暂不包含在本次范围。首次需要通过系统文件选择器授权游戏存档目录；原位写入不可用时可复制导入、保存后导出配对文件。

参考 IPA 仅用于本地只读对照；未执行其中的程序，也未复制其应用代码或资源进入项目。既有游戏像素素材和目录的来源与使用边界见 [GAME_ASSET_PROVENANCE.md](GAME_ASSET_PROVENANCE.md)、[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 和 [USER_ASSET_LIBRARY.md](USER_ASSET_LIBRARY.md)。
