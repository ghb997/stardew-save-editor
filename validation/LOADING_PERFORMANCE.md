# 本机存档加载优化 · 0.5.2（13）

修复选择本机存档后，主页和地图在界面线程重复遍历整份 XML 的问题。

- 农场概览由文件后台服务在载入时生成一次，主页、地图和检查保存页共用；保存、恢复或重新读取成功后，用新文件对应的概览替换。
- XML 后代遍历改为按需迭代，保持原有先序及地点匹配优先级，找到地点后停止查找。动物和字典统计不再创建完整节点数组。
- 文件内容不可变，SHA-256 在创建文件快照时计算一次，供事务校验和界面观察复用。
- 读取期间依次显示恢复检查、文件读取、存档解析和农场整理。识别完成后解除编辑锁，文件来源书签和备份列表在后台更新。
- 保留配对文件校验、外部修改检测、事务备份、回滚和未知 XML。没有减少保存校验来换取速度。

新增回归覆盖遍历顺序与提前停止、嵌套地点匹配、加载阶段与保存后概览刷新，以及大于 5 MB 的本机合成存档。性能诊断输出仅含大小与耗时，不输出存档内容或路径。

## 合成本机存档计时

本轮合成存档含 30,000 条未知数据记录，配对文件共 8,163,552 字节（约 8.16 MB）。测试确认原始文件未变、未知记录仍完整保留。下面是同一次 Debug 测试的后台加载阶段计时：

| 阶段 | 耗时 |
| --- | ---: |
| 上次保存状态与恢复检查 | 0.418 ms |
| 读取文件及文件快照 | 14.764 ms |
| 解析存档 | 518.868 ms |
| 整理农场概览 | 0.154 ms |
| 合计 | 534.205 ms |

合计从后台加载中的恢复检查开始，到农场概览生成结束；不包含系统文件选择器、目录发现、界面绘制或后续书签与备份列表更新。它不是“点选文件到界面可操作”的真机端到端计时，也不是多轮性能基准。

同一份已解析树上的“查找 Farm 地点”子步骤，旧式完整展开为 197.160 ms，新的按需查找为 0.037 ms。这个比较仅用于确认该查找避开无关地点的完整展开，不能当作整段加载的前后提升倍数；存档结构和 Farm 的位置会影响结果。

复现本轮测试范围：`VALIDATION_TEST_SCOPE=loading bash scripts/validate-on-macos.sh`。省略环境变量时默认运行完整测试。

合成存档与模拟器计时不能代替用户设备、本机文件提供器和真实存档的测量。本轮未读取或上传用户的真实存档，也未进行签名安装、真机计时或游戏内读档与隔日往返。
