两条新增 UI 流程实际执行了进程结束和重新启动：

1. 修改字段 → 等待“草稿已暂存” → 结束应用 → 打开本地副本 → 恢复并核对值 → 再次重启 → 放弃并核对原值。
2. 修改字段 → 仅保存应用副本 → 结束应用 → 重开并核对值 → 查看“已保存，待导出”、时间与空间信息 → 打开目标核对导出页，并确认尚未选定目标时不提供写入按钮。
