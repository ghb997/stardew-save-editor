# 第 2 套：轻量农场手账

用户从三套方案中选择了第 2 套。视觉依据是 `selected-journal-reference.png`，此次直接在现有 iOS 17+ SwiftUI 应用内实现。

- 奶油色背景、胡桃木色文字、少量陶土色重点操作；深色模式使用低饱和森林底色。
- 去掉厚木框、背景噪点、多重描边和面板阴影；共享表单、列表、页头及按钮保持统一。
- 工具页默认展示角色、背包、装备、关系、天气、地图六个入口，普通字号双列排列，大字号单列并自动换行。
- “全部功能”展开现有五个分类与跨分类搜索，标题旁搜索按钮可直接打开并聚焦搜索。全部 17 项工具、计算器及检查保存入口仍可访问。
- 本地副本、备份管理使用轻量列表；“更多”提供重新读取/校验和关闭副本。数据操作、草稿确认、文件导入及双文件导出规则沿用构建 19。
- 检查保存按钮保留在独立底部区域；原生底栏提供主页、追踪、工具、设置。
- 顶部农舍、小鸡与山景仅为装饰；农场名、玩家名、日期、草稿状态和待保存项数来自当前存档。

文字使用 iOS 系统字体与中文回退，支持 Dynamic Type。原生系统状态栏、TabView 和安全区保留，因此真实设备的可用内容高度与无系统栏的概念图不同。小屏允许滚动，iPad 内容限制宽度。

生成图像的来源见 `GENERATED_ASSETS.md`；实际截图对照与交互验证将记录于项目根目录 `design-qa.md` 和 `validation/BUILD20_VERIFICATION.md`。
